# Book Catalog (WPF + SQLite)

Desktop application for managing a simple book catalog.

## Tech Stack

- C#
- WPF (.NET Framework 4.8)
- SQLite
- Visual Studio

## Features

- Add books (title, author, year)
- Delete selected book
- Search books by title
- Display full book list
- Persistent storage using SQLite

## Architecture

The project is divided into layers:
- Models - data structures
- Data - database access layer
- Services - business logic
- UI - WPF interface

## Database

SQLite database is used for local storage of books.

## How to run

1. Open solution in Visual Studio
2. Restore NuGet packages
3. Build and run project
